# Dorandoran v2 재작업 지시서 (2026-08-11 Figma 업데이트 반영)

Figma 와이어프레임이 크게 개편됐다. 이 문서가 v1(기존 구현) → v2(새 스펙) 전환의
유일한 근거다. **여기 없는 문구·기능·색·아이콘은 절대 지어내지 말 것.** 텍스트는
`docs/figma-wireframe-spec-v2/*.txt`에서 그대로 가져오고, 레이아웃은
`docs/figma-wireframe-spec-v2/screenshots/*.png`를 최대한 그대로 따른다.

## 핵심 변화
- 하단 탭바가 5개(홈/내동행/알림/채팅/만들기) → **4개(홈/내동행/동네소식/만들기)** 로 바뀜.
  `채팅`은 없어지고 `알림`은 `동네소식`(동네 게시판)으로 대체됨.
- 헤더는 이제 `로고 | 알림 | 내 정보` 3개 (텍스트 라벨, 클릭 목적지 스펙에 없음 → 비활성 유지).
- 로그인 후 "동행 만들기"(모임을 새로 만드는 것)와 "동행 참여하기"(남이 만든 모임에 들어가는 것)가
  **명시적으로 갈라지는 선택 화면**이 새로 필요하다 (사용자 직접 요청, 아래 8번 참고).
- 기존 v1의 `/login`, `/create`(2버튼 게이트), `/location`, `/create/welcome`,
  `/home-alt`, `/home/notifications`, `/location/denied`, `/feed`, `/feed-alt`,
  `/create/step-3` 는 대응하는 Figma 노드가 더 이상 존재하지 않는다 → **삭제**.

## ⚠️ 진입 플로우 정정 (사용자 직접 지시, 최우선 반영)

처음 계획했던 "일단 둘러보다가 만들기/참여 버튼 누를 때만 로그인 뜬다" 구조는 틀렸다.
**로그인은 앱 진입과 동시에 실행된다.** `/splash` 화면 자체(문구·버튼 2개)는 Figma
스펙 그대로 렌더링하되(문구 삭제 금지), **두 버튼("카카오로 시작하기", "그냥 둘러보기")
전부 다 `/login/kakao?next=/start/welcome`으로 보낸다** — 버튼 종류와 무관하게 로그인
플로우로 직행. 로그인 → 환영(06) → 선택화면(동행 만들기/동행 참여하기) 순서는 아래
그대로 유지한다. `/home`(둘러보기)은 이제 최초 진입 화면이 아니라 **"동행 참여하기"를
선택한 이후에 도달하는 화면**이다.

## 라우트 맵 (v1 → v2)

   `/login/kakao?next=/start/welcome`로 연결**(위 정정사항).
2. `/location-permission` — 변경 없음 (위치_권한.txt: "가까운 것만 보여드릴게요" + "위치 허용하기").
   이 화면의 도달 시점은 로그인 이후 흐름 중 적절한 지점(예: `/start/choose`에서 "동행 참여하기"
   선택 직후, `/home` 진입 전)으로 자연스럽게 넣는다. `/location/manual`(3번)로 갈 방법이 스펙엔
   명시적 버튼이 없으므로, 이 화면 안에 텍스트 링크 하나를 추가한다 — 라벨은 03 화면 자신의
   텍스트인 **"직접 입력"** 을 그대로 재사용한다(새 문구 발명 아님).
3. `/location/manual` (NEW, 구 `/location/denied` 대체) — `03_내_위치_직접_선택.txt`.
   "내가 위치한 동네를 선택해주세요" + "직접 입력" + 지도영역 placeholder + "선택" 버튼 → `/home`.
4. `/home` — **내용 교체**, 그리고 **더 이상 진입점이 아니라 "동행 참여하기"를 고른 뒤 도달하는
   화면**. `04_홈_둘러보기.txt` + `screenshots/04_홈_596-26.png` 기준.
   상단(로고/알림/내정보) → "모집중인 추천 동행" 타이틀 → 가로 캐러셀("곧 시작하는 모임", 카드 2장:
   달토끼/화봉동 "모여서 대보름 호두 까기", 귀여운양양/송정동 "수영 교실 등록 함께할 분") →
   정렬 칩(빠른 순 / 가까운 순 / 소요시간 순, "빠른 순"이 선택된 상태 스타일) → 세로 카드 리스트

**진입 순서 (splash 두 버튼 전부 공통)**: `/splash` → `/start`(05, 로그인 유도) →

## 지켜야 할 기존 원칙 (v1 라운드 5회 적대적 리뷰에서 확립됨, 여전히 유효)
- `?from=`/`?next=` 같은 쿼리 기반 back-nav는 반드시 `lib/safePath.ts`의 `safeInternalPath`를 거칠 것
  (오픈 리다이렉트 검증됨, 재발 금지).
- `WireframeLayout`은 `justify`/`items` prop으로만 정렬을 바꿀 것 — className에 `justify-center`/`items-center`를
  직접 넣지 말 것(과거 실제로 깨졌던 패턴).
- 스펙에 없는 목적지·문구·아이콘은 절대 만들지 말 것. 애매하면 비활성(회색, cursor-not-allowed span)으로
  처리하고 지어내지 않는다.
- `npm run build` 통과 확인 후 커밋(push는 하지 말 것 — 검수 후 내가 push한다).
